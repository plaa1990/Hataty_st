--------------------------------------------------------------------------------
🚀 วิธีเปิดใช้งาน (เริ่มต้นได้ทันที):
--------------------------------------------------------------------------------
[แบบที่ 1: เปิดใช้งานบนเครื่องคอมพิวเตอร์ของคุณ (Offline 100%)]
1. แตกไฟล์ zip ทั้งหมดลงในโฟลเดอร์บนเครื่องของคุณ (Extract All / Unzip)
2. ดับเบิ้ลคลิกไฟล์ "index.html" เพื่อเปิดหน้าหลัก Hatafuku Studio 2.0 ทันที
   * หรือเปิด "standalone-index.html" สำหรับเวอร์ชันฉุกเฉินไฟล์เดียว
3. ระบบจะทำงานแบบ Offline 100% ทันทีโดยไม่ต้องต่ออินเทอร์เน็ต

[แบบที่ 2: นำไฟล์ไปอัปโหลดขึ้นเว็บโฮสติ้ง (Web Hosting / Server)]
ไฟล์ทั้งหมดใน ZIP นี้เป็นเว็บประเภท Static Web Application พร้อมใช้งานทันที
โดยไม่ต้องติดตั้ง Node.js หรือฐานข้อมูลบนเซิร์ฟเวอร์:
• cPanel / DirectAdmin / Web Hosting ทั่วไป:
  1. แตกไฟล์ zip ทั้งหมด
  2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด (index.html, assets, .htaccess, ฯลฯ) เข้าโฟลเดอร์ public_html
  3. เปิดเบราว์เซอร์เข้าโดเมนเนมของคุณ เว็บจะเปิดทำงานทันที!
• Netlify: ลากโฟลเดอร์ที่แตกแล้วไปวางในหน้า "Deploy manually" (Netlify Drop)
• Vercel / GitHub Pages / Cloudflare Pages / Firebase Hosting: รองรับได้ทันที 100%
